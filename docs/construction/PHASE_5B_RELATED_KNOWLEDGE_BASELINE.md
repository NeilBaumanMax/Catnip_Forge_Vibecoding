# Phase 5b 相关知识选择基线

日期：2026-09-09。起点：`idea_to_production` / `4fe24a87`。

- “解问题”根据用户正在描述的问题查询既有本地收藏，展示相关候选；不抓取原文、不查询新的外部服务。
- 候选默认全部不选。只有用户明确勾选的卡片，才通过既有 Main 选择 IPC 校验并转换为本次 `knowledge` Context。
- 问题变化时旧选择失效；找灵感不自动携带历史知识。未选择、伪造 ID 或查询失败均不得静默加入 Context。
- 最小验收覆盖发现、默认未选、显式选择、请求携带和 Store 选择反例；不测试 Access Secret、知乎、DeepSeek 或硬件。
