## 工程决定（不改变产品行为）

- E001 / Phase 0：新文档在 `docs/product` 和 `docs/construction` 建立，旧文档原样保留引用。避免把历史接力状态误作本轮事实。

- E003 / Phase 2 候选：调查现有 JSON user-data 后优先选择原子写入的小型 JSON store；在持久化/损坏/重启测试前仍为 A3 假设，不宣称已实现。
- E004 / Phase 3 前置：现有 Agent 跳过权限确认，不能直接接收 Explore 请求；先验证最小受限执行模式和结构化输出能力，复用队列而不造通用协议。门禁未通过不开放交接。
