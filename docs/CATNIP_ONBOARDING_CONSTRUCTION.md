# 猫薄荷新手旅程施工文档

## 1. 目标

让首次进入 Catnip Forge 的用户在约 5 分钟内认识 Agent、仓库、监视器、任务管理器、编辑器和猫薄荷软件助手。猫薄荷以游戏新手任务式的聚光引导带用户亲自点击关键入口，而不是播放与真实界面脱节的幻灯片。

基础旅程必须完全离线，不调用 DeepSeek/Qwen，不修改文件，不编译、不烧录、不连接串口，也不上传附件。

## 2. 首次触发与重播

- 首次 API Key 配置窗口仍拥有最高优先级；只有 `firstRun=false` 后才显示新手邀请。
- 未记录状态时进入主界面约 900ms 后显示非阻塞邀请。
- “稍后提醒”在 24 小时后再次邀请；“我已经会了”永久停止自动邀请。
- 完成后写入 `vibeide.onboarding.catnipJourney`，同一教程版本不再自动出现。
- 当前状态版本为 v5；旧 v1/v2/v3/v4 状态会被安全忽略，让已经完成过旧版旅程的用户重新收到修复版邀请，不需要删除整个用户数据目录。
- 打开猫薄荷软件助手，点击顶部功能栏中亮暗主题按钮旁的“？”可随时从头重播。
- 工作台自动 smoke 环境禁用首次邀请，避免引导层污染既有自动验收。

## 3. 旅程内容

当前 v5 旅程共 23 步：

1. 安全边界与旅程说明。
2. 左侧开发 Agent、追加要求和排队。
3. 用户亲自点击“仓库”。
4. Skill“打开目录”“立即同步”“新建 Skill”的具体用途。
5. 硬件工程与参考代码的区别。
6. 用户亲自点击“监视器”。
7. 串口收发与配置分区。
8. 用户亲自点击“任务管理器”。
9. 刷新工程、选择工程、点击编译。
10. 刷新设备、选择串口、点击烧录。
11. 日志、事件卡片与最近任务结果。
12. 用户亲自点击“编辑器”。
13. 资源树、多标签、保存和回收站删除。
14. 收起/展开 Agent 与分栏宽度调整。
15. 编辑器字号减小、增大和重置。
16. 历史对话持久化、重命名、置顶和删除。
17. 专业视图的工具、状态和诊断信息。
18. Agent 输入与追加要求。
19. 添加图片和文档附件。
20. 插入一个或多个 `@Skill`。
21. 用户亲自点击右下角猫薄荷。
22. 猫薄荷聊天机器人、亮暗模式、大小、拖动和教程重播。
23. 以 “One Prompt, Working Hardware” 完成旅程。

需要亲自操作的步骤禁用普通“下一步”，只有点击当前高亮标签才会推进。目标不存在时必须显示“跳过此步”，不能把用户困在遮罩层。

## 4. 技术结构

- `electron/src/renderer/components/CatnipOnboarding.tsx`：数据驱动步骤、状态机、目标测量、持久化和键盘操作。
- `data-tour-id`：稳定定位 Agent、输入区、四个标签、四个内容面板以及 Skill、Build/Flash、历史、编辑器字体和猫薄荷入口；禁止依赖中文文本定位。
- `electron/src/renderer/styles/apple.less`：邀请卡、聚光框、玻璃材质、锚点定位、窄窗口和辅助功能适配。
- `electron/scripts/verify_catnip_onboarding.cjs`：校验步骤引用的目标全部存在，并检查离线安全承诺、持久化、重播、缺失目标降级和减少动态效果规则。

旅程开始时自动展开左侧 Agent 区并关闭猫薄荷聊天浮层。教程不改变用户保存的小猫位置、尺寸、主题或左右分栏宽度。

进入历史对话、专业视图、输入、附件和 Skills 步骤前，教程必须自动恢复被用户收起的 Agent；进入猫薄荷说明步骤时必须保证助手面板已经打开。教程不能只在进入步骤时恢复一次：步骤停留期间每 250ms 检测受管理目标，用户再次收起 Agent 或关闭助手后也要重新展开。这两类受管理目标在恢复期间显示“正在恢复”，不允许以黄色缺失提示跳过。

## 5. Apple 交互基线

- 高亮框和讲解卡从当前屏幕位置连续移动，步骤切换不闪跳。
- 聚光框在教程运行期间逐帧复测当前目标位置，必须跟随分栏收起/展开、拖动和窗口布局变化，不能停留在旧坐标。
- 目标控件保持直接可点击，聚光遮罩自身不截获指针。
- 动画可随时被退出、返回或下一次点击打断。
- 默认使用克制、无回弹的位移和材质过渡。
- `prefers-reduced-motion` 下取消位移动画，仅保留短淡变。
- `prefers-reduced-transparency` 下使用实色表面；高对比度模式增加明确边框。
- `Esc` 退出，左右方向键支持返回/前进；所有按钮保持键盘焦点反馈。

## 6. 安全边界

- 基础旅程只解释和切换页面，不自动发 Agent 消息。
- 不自动打开串口，不枚举之外操作设备，不触发 Build/Flash。
- 不选择、读取或上传用户附件。
- 不读取、不展示 API Key。
- 后续如增加“第一次编译”或“图片识别”实战，必须作为单独的可选任务，并在执行前再次说明副作用和云端上传边界。

## 7. 验收

自动验收：

```powershell
npm.cmd --prefix electron run verify:onboarding
npm.cmd --prefix electron run verify:onboarding-ui
npm.cmd --prefix electron run typecheck
npm.cmd --prefix electron run build:renderer
git diff --check
```

人工 UI 验收：

1. 清除 `vibeide.onboarding.catnipJourney` 后重载，确认首次邀请出现。
2. 验证开始、稍后提醒、我已经会了和助手顶部“？”入口重播。
3. 逐步点击仓库、监视器、任务管理器、编辑器，确认高亮与内容匹配。
4. 中途收起左侧、在第 22 步关闭猫薄荷助手、调整窗口尺寸、切换深浅主题并按 `Esc`，确认目标会恢复且教程不会卡死。
5. 验证过程中没有 Agent 请求、Qwen 请求、文件写入、编译、烧录或串口连接。
